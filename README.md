# 늘벗이 팀 🌱 — 세종늘벗학교 픽셀 AI 팀 비서

게임처럼 픽셀 캐릭터 **4인 팀**(팀장·기획·디자인·실무)이 방 안에서 협업하는 데스크톱 AI 비서.
간단한 질문은 팀장이 즉답하고, 문서 작업은 팀이 **회의**를 열어 처리합니다.
특히 **기획 단계에서 Claude와 Gemini 두 AI가 각자 방안을 내고 팀장이 최적안으로 종합**합니다.

## 캐릭터 (역할 = AI 페르소나)

| 캐릭터 | 역할 | 하는 일 |
|--------|------|---------|
| 👑 팀장 | 총괄·종합 | 업무 접수, 두 기획안 비교 → 최적안 결정 |
| 📋 기획 | 방안 제안 | **Claude + Gemini** 에게 각각 접근안을 받아옴 |
| 🎨 디자인 | 형식·톤 | 문서 종류·구성·말투·분량 가이드 |
| 🔧 실무 | 작성 | 바로 쓸 수 있는 완성 초안 작성 |

## 에이전트 팀장 (연속 대화)

팀장이 **전체 대화를 기억하며 이어서** 일하는 에이전트예요(정해진 순서만 도는 게 아님). 필요하면 **스스로 판단해** 업무 폴더를 검색·열람하고, 기획회의를 열고, 초안을 만들고 저장합니다.

- **보내기** — 대화·질문. "오늘 일정?"은 즉답, 그 외는 팀장이 알아서 처리.
- **🏢 팀에게 맡기기** — 문서 작업 요청. 팀장이 자료를 스스로 찾아 참고하고 초안을 완성.
  - 예: `작년 입교식 안내문 찾아서 그 형식으로 2026 입교식 안내문 써줘`
- **이어서 수정** — 초안을 받은 뒤 그냥 "더 정중하게", "분량 줄여줘"라고 말하면 **그 초안을 이어서** 고쳐요.
- **🔄 새 작업** — 완전히 다른 일로 넘어갈 때 대화·초안 기억을 비움.

> ⚠️ 에이전트는 판단할 때마다 API를 여러 번 부르므로 **회의보다 느리고 비용이 더** 듭니다(그만큼 연속적). 속도가 급하면 `src/agent.js`의 `effort: 'medium'`을 `'low'`로 낮추세요. Claude 키가 없으면 기존 '팀 회의' 방식으로 자동 대체됩니다.

## 실행

```
npm install     (처음 한 번)
```
`start-server.bat` 더블클릭 → 브라우저 자동 실행 (http://localhost:4000)

## AI 켜기 (키 설정)

키가 **없어도** 일정 안내는 즉답, 팀 회의는 흐름을 보여주는 **데모 모드**로 동작합니다.
진짜 협업을 켜려면 `start-server.bat` 을 메모장으로 열어 아래 REM 을 지우고 키 입력:

```
set ANTHROPIC_API_KEY=sk-ant-...        (필수: 팀장/기획/디자인/실무)
set GEMINI_API_KEY=...                  (선택: 기획 두 번째 의견)
set MODEL=claude-opus-4-8               (Claude 모델, 비용시 claude-haiku-4-5)
set GEMINI_MODEL=gemini-2.0-flash       (Gemini 모델)
```

- **Claude 키**: platform.claude.com 콘솔에서 발급
- **Gemini 키**: [Google AI Studio](https://aistudio.google.com/apikey) 에서 무료 발급
- Claude만 있어도 팀은 동작(기획이 Claude 안만 제시). **둘 다 있으면 듀얼 AI 협업**.
- Gemini만 있으면 모든 역할을 Gemini가 담당.

## 업무 폴더 연동 📁

`📁 업무 폴더` 버튼을 누르면 실제 업무 폴더(`g:\...\2026 학교 업무\업무 폴더`)와 연결됩니다.

- **목록 보기**: 폴더 안 문서를 탐색(검색·`문서만` 필터). 민감파일은 자동 제외.
- **기존 문서 참고**: PDF나 텍스트 파일을 `📎 참고로 첨부` → 팀에게 맡기면 그 문서를 참고해 비슷한 스타일로 작성
  - HWP 원본은 못 읽지만 **PDF 짝**이 있으면 그걸로 참고돼요 (문서를 HWP+PDF로 보관하는 관례 활용)
  - ⚠️ 참고한 문서 내용은 작성을 위해 외부 AI(Claude/Gemini)로 전송됩니다
- **초안 저장**: 산출물 패널의 `💾 업무 폴더에 저장` → `늘벗이_산출물` 폴더에 `.txt`로 저장(구글드라이브 자동 동기화)

**자동 제외(안전장치)**: 비밀번호 폴더, 인증서(.cer/.key 등), 숨김/시스템 폴더(.venv 등), 폰트 파일.

**폴더 위치가 다르면**: `my-keys.bat` 에 `set WORK_DIR=D:\경로\...` 한 줄을 추가하면 바뀝니다.

## 다른 선생님에게 배포 — 각자 자기 PC에 설치 (권장)

각 선생님이 **자기 PC의 업무 폴더**를 쓰려면, 앱이 그 선생님 PC에서 돌아야 해요(중앙 서버는 다른 PC 폴더를 못 봄). 그래서 각자 설치하는 패키지를 만들어 배포합니다.

**신현종 선생님(배포자)이 할 일:**
1. **한도 건 공유 키 준비** — Anthropic 콘솔에서 `늘벗이-공유` 워크스페이스 + 월 지출한도(예: $20) + 그 안의 API 키 발급
2. **`teacher-keys.bat`** 를 메모장으로 열어 그 키(와 Gemini 키) 입력 (ASCII만)
3. **`make-teacher-package.bat`** 더블클릭 → `..\Neulbeot-Teacher-Package.zip` 생성 (node_modules 포함, 교사는 설치 불필요)
4. 그 **zip을 각 선생님에게** 전달

**각 선생님이 할 일:**
1. zip **압축 풀기** (되도록 한글경로 아닌 곳)
2. **`start-server.bat`** 더블클릭 (Node.js 없으면 설치 안내 뜸 → nodejs.org LTS 설치 후 재실행)
3. 브라우저 열리면 이름 입력 → **📁 업무 폴더 → 📂 폴더 설정**으로 **자기 폴더 선택** → 자동 분석
4. 자세한 건 패키지 안의 `설치-먼저읽기.md`

> 이 방식은 각 선생님이 **자기 PC 폴더를 완전하게** 쓰고 자동 분석까지 됩니다. 비용은 3번 공유 키(한도)로 통제돼요.

## (참고) 한 대만 켜서 브라우저로 공유하는 방식 (중앙 서버)

이 서버 한 대만 켜두면 다른 선생님들은 **브라우저 주소**로 접속해서 각자 씁니다(설치 불필요).

**1) 한 번만: 방화벽 열기** — `setup-firewall.bat` 을 **관리자 권한으로** 실행(포트 4000 허용).

**2) 서버 켜기** — `start-server.bat` 실행하면 검은 창에 접속 주소가 떠요:
```
내 PC:      http://localhost:4000
다른 선생님: http://10.127.18.xxx:4000   ← 이 주소를 다른 선생님께 공유
```

**3) 각 선생님** — 위 주소로 접속 → 처음에 **이름 입력**(예: 김철수). 이름별로 대화·초안이 분리돼요(안 섞임). 상단 `👤이름` 클릭하면 전환.

### 각 선생님의 파일 쓰는 법 (두 가지)
- **⬆️ 파일 올리기** — 자기 PC 파일(PDF/텍스트)을 그때그때 올려 참고. **위치 상관없이 누구나** 됩니다. (제일 간단)
- **📂 폴더 설정** — 주소 입력 없이 **탐색기처럼 폴더를 클릭해서 선택**해요(드라이브 → 폴더 → "✅ 이 폴더 선택"). 소유자는 자기 PC 아무 폴더나, 다른 선생님은 공유 폴더 안에서만.
  - ⚠️ 안전을 위해 폴더 지정은 **`shared-root.txt`(공유 폴더 루트)** 안으로만 허용해요. 없으면 폴더 지정은 꺼짐(업로드를 쓰면 됨).
  - 공유 드라이브/NAS를 쓸 거면: 프로젝트 폴더에 `shared-root.txt`(UTF-8)를 만들고 그 안에 공유 폴더 경로 한 줄(예: `\\NAS\학교공유` 또는 `Z:\학교공유`)을 적으세요.

### 개인정보 보호
- **소유자**(`owner.txt` = `신현종`)는 자기 업무 폴더를 그대로 씁니다. 다른 선생님은 **자기 폴더/올린 파일만** 보고, 팀장도 남의 폴더는 안 뒤져요.
- 손님이 만든 문서는 **⬇️ 다운로드**로 자기 PC에 받습니다(폴더 미설정 시 서버 `outputs/`에 임시 저장 후 다운로드).

### 비용 관리 (공유 서버만 한도 걸기)
1. Anthropic 콘솔 → **새 워크스페이스**(예: `늘벗이-공유`) → **월 지출 한도**(예: $20) 설정
2. 그 워크스페이스에서 **API 키 발급** → `my-keys.bat` 의 `ANTHROPIC_API_KEY` 에 이 키 사용
3. 그러면 공유 서버 사용량만 그 한도에 묶이고, 개인 실험은 다른 키로. (Gemini도 구글 콘솔에서 별도 한도 가능)

> ⚠️ 학교 밖에서도 접속하려면 기존 Cloudflare 터널 방식을 쓰면 됩니다. 손님 산출물은 소유자 PC의 `늘벗이_산출물` 폴더에 임시로 쌓이니 가끔 정리하세요.

## 구조
```
src/
├─ server.js    Express + API(/api/chat, /api/team SSE, /api/schedule)
├─ ai.js        Claude + Gemini 공용 호출 모듈
├─ brain.js     팀장 짧은 대화(규칙 + Claude)
├─ team.js      팀 회의 파이프라인(듀얼 AI → 종합 → 초안)
└─ schedule.js  2026학년도 학사일정
public/
├─ index.html / css/style.css
└─ js/
   ├─ sprites.js  픽셀 도트맵 + 역할별 색상
   ├─ game.js     방/4인 팀/회의 연출
   └─ chat.js     대화·회의(SSE)·산출물 패널
```
