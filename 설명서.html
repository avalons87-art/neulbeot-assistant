늘벗이 — 학교 업무 지원 AI 비서

내 컴퓨터에서 도는 AI 비서예요. 내 업무 폴더의 자료를 참고해 공문·안내문·계획안 초안을 만들고, 학사일정을 챙기고, 손글씨를 텍스트로 옮겨 줍니다.

늘벗이 팀

설치는 딱 두 가지—① Node.js 설치, ② start-server.bat 실행—이면 끝나요. 처음 켜면 설정 마법사가 이름·학사일정·업무폴더·API 키를 순서대로 안내합니다. 아래 순서대로만 따라오시면 됩니다.

✓

먼저 준비할 것

  • Node.js 설치 — 함께 드린 설치파일(또는 nodejs.org의 LTS 버전, 22 이상)을 설치하세요. 이 프로그램이 도는 엔진이에요.
  • 업무 자료를 한 폴더에 모아 주세요. 늘벗이는 지정한 하나의 업무 폴더를 참고합니다.
  • 학교 업무계획 PDF 한 부. PDF가 없으면 한글(HWP)에서 전체 복사(Ctrl+A→C)해 붙여넣어도 되지만, 표가 있으면 인식 오류가 있을 수 있어요.
  • 본인 AI API 키 — Claude · Gemini · GPT 중 하나 이상. 공유용 키는 사용량 제한이 있어 잘 안 될 수 있어요. 개인 키를 권장합니다.
🔑
API 키는 어디서 받나요? 아래 중 하나 이상만 있으면 돼요. 발급받은 키는 내 컴퓨터에만 저장됩니다.
  • Claude → platform.claude.com (결제 등록 필요)
  • Gemini → aistudio.google.com (무료 등급 있음)
  • GPT (OpenAI) → platform.openai.com
  • OpenRouter → openrouter.ai/keys (키 하나로 여러 모델 · 모델 이름은 openrouter.ai/models)
!

시작 전에 꼭 알아두기

🌐
완전한 오프라인은 아니에요. 업무 파일 자체는 내 컴퓨터에만 있고 어디로도 올라가지 않아요. 다만 문서 작업을 할 때는 AI에게 보내는 내용(질문·참고 텍스트)만 인터넷으로 선택한 AI 회사(Claude/Gemini/GPT) 서버에 전송됩니다.
🔒
실제 학생 개인정보(실명·주민번호·연락처·성적·생기부 등)는 AI에 입력하지 마세요. 문서 작업 시 입력 내용은 외부 AI 서버로 전송됩니다. 비밀번호 폴더·인증서·숨김 폴더는 자동 차단되고 학생 이름은 결과물에서 자동 OO 처리되지만, OO는 “결과물”에만 적용돼요 — 실명이 든 원본을 넣으면 그 실명은 그대로 전송됩니다. NEIS/나이스 자료는 넣지 마세요.
🧠
학습 사용 여부. Claude·GPT는 API로 보낸 내용을 학습에 쓰지 않아요(기본). 다만 Gemini 무료 등급은 예외일 수 있으니, 조금이라도 민감한 자료는 Claude·GPT(또는 Gemini 유료)를 쓰세요. 넓게 공유·공식화 전엔 학교·교육청 정보보안 담당 확인을 권합니다.
🗂️
파일은 함부로 안 바뀌어요. 파일 이동·복사·수정·삭제는 화면에서 승인(✅)한 뒤에만 실행돼요. 삭제는 진짜 지우지 않고 휴지통 폴더로 옮기고(복구 가능), 정리는 기본이 복사(원본 보존)예요.

설치하기

순서대로 한 번만 하면 됩니다.

  1. Node.js를 먼저 설치하세요. 설치파일을 실행하고 계속 > 계속으로 끝내면 돼요.
  2. 받은 압축파일(Neulbeot-Teacher-Package.zip)을 압축 풀기. 되도록 한글이 없는 경로(예: 바탕화면)에 두면 더 안전해요.
  3. 업무 폴더를 미리 백업(복사본 하나 만들기)하세요. 늘벗이가 파일을 정리·복사할 수 있으니 혹시 모를 대비예요.
  4. 풀린 폴더의 start-server.bat을 더블클릭. 검은 창이 뜨고 3초 뒤 브라우저가 열려요. 안 열리면 주소창에 localhost:4000.
🖥️
검은 창은 켜둔 채로 두세요. 그 창을 닫으면 늘벗이가 꺼져요. 처음 실행 때 Node.js 안내가 뜨면 설치 후 다시 실행하면 됩니다.
2

첫 실행 — 설정 마법사

처음 켜면 4단계가 순서대로 떠요. 그대로 따라가면 됩니다.

  1. 이름 입력 — 늘벗이가 이 이름으로 기억하고 설정을 저장해요.
  2. 학사일정 올리기 — 준비한 업무계획 PDF를 올리거나 내용을 붙여넣으면, 날짜·행사로 정리해 그 일정을 따라요.
  3. 업무 폴더 선택 — 윈도우 탐색기 창에서 내 업무 폴더를 고르면 돼요.
  4. 업무 확인 — 늘벗이가 폴더·일정을 보고 “선생님 업무가 이런 것 같아요”라고 정리해줘요. 맞는지 확인하고 고친 뒤 시작!
🔑
API 키 넣기 — 오른쪽 위 🔑를 눌러 메인 AI(Claude / Gemini / GPT / OpenRouter)를 고르고 키를 입력하세요. 원하면 어시스턴트(보조 AI)도 따로 지정할 수 있어요. 저장하면 그 AI로 바로 작동합니다.
